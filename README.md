# Pixel Trade WP

🛍️ **Pixel Trade WP** — hybrid WordPress + React e-commerce platform.  
The backend is powered by **WordPress/PHP**, while the frontend (product catalog, search, interactive UI) is built using **React**, providing a modern, responsive shopping experience with **AI-powered features** and **multilingual support (Russian, Romanian, English)**.

## 🚀 Features

✔️ Custom WordPress backend with product management  
✔️ React-powered frontend with SPA-like behavior  
✔️ Product listing, categories, and search  
✔️ Single product pages with dynamic data  
✔️ Responsive design for mobile and desktop  
✔️ Component-based React architecture  
✔️ Smooth integration between WP and React  
✔️ AI-powered features (product recommendations, smart search, automated descriptions)  
✔️ Multilingual support: Russian, Romanian, English  
✔️ Potential to extend with plugins like WooCommerce or custom APIs

## 🧠 Technologies Used

✔️ **WordPress / PHP** — backend, CMS, database management  
✔️ **React** — frontend UI, components, SPA-like experience  
✔️ **CSS / SCSS** — responsive styling  
✔️ **JavaScript** — interactivity and utilities  
✔️ **REST API / WP API** — communication between React frontend and WP backend

## 📦 Installation

1. Clone repository:  
   ```bash
   git clone https://github.com/Karataev-Daniil/Pixel-Trade-WP.git
Place the theme in WordPress themes folder:

wp-content/themes/pixel-trade
Install dependencies for React frontend:

cd src
npm install
Run React frontend in development mode:

npm start
Activate the theme in WordPress admin and configure pages.
